# Profile sourcing

The first edition uses the public [GitHub profile](https://github.com/kugtong33)
and the following public repositories. The deployment does not need a GitHub
API token or make any runtime GitHub API calls.

| Source | Evidence used |
| --- | --- |
| [`GET /users/kugtong33`](https://api.github.com/users/kugtong33) | Arjay Sitoy, software engineer, Philippines, `@kugtong33`, and the public avatar |
| [`labs-kube-autoscaling`](https://github.com/kugtong33/labs-kube-autoscaling) | Reproduces Kubernetes HPA scale-up and cooldown in KinD under synthetic load |
| [`labs-aws-profiler`](https://github.com/kugtong33/labs-aws-profiler) | Shell CLI to switch AWS profiles with project-aware checks |
| [`labs-local-llm`](https://github.com/kugtong33/labs-local-llm) | Runs local GGUF models through llama.cpp or Ollama |
| [`labs-wikirag`](https://github.com/kugtong33/labs-wikirag) | Compares Wikipedia-backed retrieval-augmented generation approaches |

The short first-person bio is editorial synthesis, not a quote from GitHub.
The projects are explicitly public labs, not employer projects or evidence of
commercial outcomes. Employer, client work, contact details, and the unrelated
social URL in the GitHub profile are not republished.

The public [GitHub avatar](https://avatars.githubusercontent.com/u/3274087?v=4)
is a cat meme rather than a headshot. The site does not republish or hotlink
the avatar.

The display face is [Chivo](https://fonts.google.com/specimen/Chivo), served
locally as a Latin WOFF2 subset. Its SIL Open Font License is packaged next
to the font under `site/assets/`.
