# Homepage redesign options

**Source Tree** was selected on the Impeccable board to replace Signal Plate.
The implementation brief is in [profile-surface.md](profile-surface.md).
Both alternatives preserve the first-person bio and the four sourced
public projects. They make the work visible earlier without inventing
employment, production results, or content.

## Source Tree

A dark, spruce-green homepage with a directory rail and a `README.md`
reading pane. The bio comes first, with real repository names and short
descriptions directly below. The rail becomes a compact topic index on
phones. The engineering cues come from actual paths and navigation,
not fake terminal prompts or editor controls.

**Choose it for:** an explicitly developer-native identity and quick
repository scanning.

## Project Workbench

A warm paper homepage organized like an engineering lab notebook.
A compact profile header gives way to a full Kubernetes experiment
sheet, with the other labs in an adjacent index. The feature depicts
the lab method, not benchmark data. On phones, the sheet and remaining
labs stack beneath the intro.

**Choose it for:** a personal site that shows how Arjay thinks about
engineering, with room for work notes and essays later.
